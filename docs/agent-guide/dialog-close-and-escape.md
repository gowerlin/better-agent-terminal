# Dialog 不因點擊外部關閉（T0563）、Esc 統一（T0567）

> 從 CLAUDE.md「Dialog 不因點擊外部關閉（T0563）、Esc 統一（T0567）」節搬出（T0595）。本檔為該節完整原文；CLAUDE.md 該節保留用途、必守規則、唯一實作位置與本檔連結。

- **Dialog / modal**（有標題列、表單或確認 / 取消按鈕、帶遮罩：Settings、配置（Profiles）、工作區設定、遠端 profile 編輯、setup wizard、刪除 / 關閉 / 重啟 / Worker 批次關閉確認、工具安裝確認、About、Snippet 編輯、app 通知、Recovery、更新通知、Claude / Codex 面板的內容 / Context / Cache / Task / Prompt History modal）只經 **[X] / 確認 / 取消**（與 Esc，見下）關閉。點遮罩、從 Dialog 內拖曳選取到外部放開都**不**關閉；setup wizard 因此不會因點遮罩被卸載（卸載 = runner cancel → rollback）。
- **遮罩一律用 `ModalOverlay`**（`src/components/common/ModalOverlay.tsx`）：只接受 `className` / `style` / `children`，型別上沒有 `onClick`。🔴 新增 Dialog 請用它，且必須有 [X] 或取消按鈕（app 通知原本只有 OK，T0563 補了 [X]，`aria-label` = `common.close`）。不要在遮罩元素上掛 `onClick` / `onMouseDown`。
- **Esc（T0567）**：一律經 `ModalOverlay` 的 `onEscape`（= 該 Dialog 的 [X]；確認類 = **取消**，不是確認），由 `src/components/common/modal-stack.ts` 統一處理（`document` bubble 階段單一 keydown listener）。🔴 Dialog 不得自己加 `keydown` listener 關閉（T0567 前 Profiles / 工具安裝確認各自掛 window listener，已移除）。
  - **只作用於最上層**：巢狀的 Dialog（遮罩元素在另一個遮罩內）在上；否則後開啟的在上；未顯示的（`checkVisibility()` 為否，例如隱藏的 agent 面板裡的 modal）略過。最上層取用 Esc 後 `preventDefault` + `stopPropagation`，window 層的快捷鍵（Claude / Codex 面板的 Esc = 中斷）不再收到。
  - **沒有 `onEscape` 的 Dialog 擋下 Esc**：在最上層時 Esc 不作用，下層也不作用。目前只有 `RecoveryPrompt`（必選決策）與 WSL / Docker / SSH setup wizard（在 `ProfilePanel`）：精靈開著時 Esc 不關精靈也不關配置面板（不卸載 = 不 cancel / rollback），只能用精靈自己的 [×] / 取消；精靈關閉後配置面板的 Esc 恢復。
  - **不搶既有的 Esc**：Dialog 內的元素已處理 Esc（`preventDefault` 或 `stopPropagation`，例如選單 / autocomplete / 檔案選擇器、`VoicePreviewPopover` 的 capture listener、xterm）時不關 Dialog；IME 組字中（`isComposing` / keyCode 229）不關。
  - 配置面板的 Esc 先取消行內的名稱編輯（新增 / 改名輸入框），再關面板；刪除確認、遠端 profile 編輯自己接 Esc。Claude / Codex 面板 window 快捷鍵內原有的「Esc 關 Prompt History / Task / 內容 modal」分支保留（焦點在輸入框時輸入框先清空並 `preventDefault`，modal 由該分支關閉，行為同 T0567 前）。
  - 🔴 新增 Dialog 要給 `onEscape`；刻意不給的要加進 `dialog-escape.test.tsx` 的 `NO_ESCAPE_DIALOGS`（source guard 逐檔計數）。
- **選單 / popover 照舊點外部關閉**：右鍵選單、`AddMenu` 下拉、Claude / Codex 的 Ctrl+P 檔案選擇器（`.claude-file-picker`）、`PathLinker` 檔案預覽（`.path-preview-overlay`）、`VoicePreviewPopover`、GitHub 面板的 `.context-menu-backdrop`。
- 驗證：`src/components/__tests__/dialog-no-outside-close.test.tsx`（Settings / Profiles / 刪除確認 / setup wizard / 工作區設定 / 關閉確認 / About / app 通知 [X] / 拖曳選取；`AddMenu` 仍點外部關閉；source guard：上列 Dialog 遮罩 class 只能經 `ModalOverlay`、`ModalOverlay` 不得帶點擊 handler、其他 `*overlay*` / `*backdrop*` 帶點擊關閉者只允許清單中的 popover / 選單）、`src/components/__tests__/remote-tools-panel.test.tsx`（安裝確認點遮罩不關閉）；e2e `e2e/t0563-dialog-no-outside-close.spec.ts`（隔離實例：Settings 點遮罩 / 拖出仍開著、[X] 關閉；Profiles 同；需先 `npx vite build`）。T0567：`src/components/__tests__/dialog-escape.test.tsx`（Settings / 工作區設定 / 確認類 = 取消 / About / app 通知 / Claude 面板 Prompt History 的 Esc；巢狀與兄弟的最上層、未顯示者略過；Dialog 內選單處理過的 Esc、IME 組字中不關；Recovery 不關且擋下層；精靈開著時 Esc 不關精靈與配置面板、不卸載，精靈 [×] 後 Esc 關配置面板；source guard：每個 `ModalOverlay` 都有 `onEscape`（`NO_ESCAPE_DIALOGS` 除外）、Dialog 檔不得自加 keydown listener（Claude / Codex 面板各 1 個既有快捷鍵 handler）、Esc listener 只在 `modal-stack.ts`）；e2e `e2e/t0567-dialog-esc.spec.ts`（隔離實例：Settings 按 Esc 關閉；配置面板開 SSH 精靈後按 Esc → 精靈與面板仍在，精靈 [×] 後 Esc 關面板；需先 `npx vite build`）。
