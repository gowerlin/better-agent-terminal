# Remote 資安（PLAN-018 T0182）

> 從 CLAUDE.md「Remote 資安（PLAN-018 T0182）」節搬出（T0595）。本檔為該節完整原文；CLAUDE.md 該節保留用途、必守規則、唯一實作位置與本檔連結。

- **TLS + fingerprint pinning**：Remote server 自 T0182 起以 `wss://` + 自簽憑證運行（`electron/remote/certificate.ts`），client 以 SHA-256 fingerprint (TOFU) 驗證。首次連線會自動寫入 `remoteFingerprint` 到 profile；後續不符即拒絕。
- **憑證儲存位置**：`app.getPath('userData')/server-cert.json`（10 年 expiry；90 天內自動重生）。**不要手動刪除**——會觸發 fingerprint mismatch 讓既有 client 全部失效。
- **Bind-interface 三選項**：
  - `localhost`（預設，`127.0.0.1`）—— 最安全，僅本機連入
  - `tailscale`（`100.x.x.x`）—— fail-closed：找不到 Tailscale 介面時直接報錯，**不會** fallback
  - `all`（`0.0.0.0`）—— 完全裸露，僅在受信 LAN 使用
- **Token 儲存**：`server-token.json` 以 Electron `safeStorage` 加密（Windows DPAPI / macOS Keychain）。Linux 無 keychain 時 fallback 到 plaintext + warn log（fork 現行行為，見 D Q1.A）。
- **QR payload 格式**（tunnel-manager）：`{ url: wss://..., token, fingerprint, mode, addresses }`——client 掃描後必須把 fingerprint 寫入 profile 才能建立 TLS 信任鏈。
- **ProfilePanel UI**：remote profile 有 read-only fingerprint 欄位 + 「Pin expected fingerprint」按鈕（手動刷新）。首次建立 profile 時欄位空白，`Fetch profiles` 成功後自動填入（TOFU）。「編輯連線」裡釘選成功後，新指紋同時寫入 profile 與對話框（之後按「儲存」不會寫回舊值）；釘選失敗在對話框內顯示原因、不寫入（T0650 / BUG-157，`handlePinFingerprint`，`src/components/ProfilePanel.tsx`）。釘選以 profile **已儲存**的 host / port / token 連線、不帶預期指紋（TOFU：接受當下回應的伺服器）。SSH 設定（`targetOS` 為 `ssh-linux` / `ssh-darwin`）的按鈕停用並顯示「請重跑設定精靈更新指紋」，`handlePinFingerprint` 也直接拒絕、不連線：釘選不經 SSH 通道，而 SSH 設定的 host 是 `localhost`、port 是遠端主機上的埠，直連會釘到（並送權杖給）本機剛好聽在該埠的伺服器（T0655 / BUG-160，`cannotPinDirectly`，`src/components/profiles/EditRemoteProfileModal.tsx`）。WSL / Docker / 舊版遠端設定不變。
- **依賴套件**：`selfsigned@^5.x`（v5 是 async API；`await selfsigned.generate(...)`，v4 同步呼叫會回 Promise 導致 `.cert.replace` undefined）。
- **降級情境**：若 `safeStorage.isEncryptionAvailable() === false`，`[Secrets]` warn log 會顯示一次；工單決策是「fallback 不阻擋啟動」，使用者可觀察 log 判斷是否需要切離 Linux 環境。
- **SSH target 與 user（T0505）**：`sshUser` 可為空。空時所有 ssh 呼叫點（`buildBaseSshArgs`，`electron/remote/ssh-args.ts`）的 argv 結尾為 `-- <host>`，由 `~/.ssh/config` 決定 user / HostName / Port / IdentityFile / ProxyJump（wizard 選 alias 即走此路，存 `sshUser: ''`）；有值時維持 `-- user@host`。host-only target 必須符合 `^(?!-)[A-Za-z0-9._:-]{1,253}$`（不得以 `-` 開頭、不含 `@`），`listSshHosts` 只列出符合者。遠端 `loginctl enable-linger` 在無 user 時用 `"$(id -un)"`。
- **SSH wizard 安裝 / 啟動（T0511，BUG-120 / BUG-121）**：server bundle tarball 頂層是 `staging/`，上傳時遠端 `tar xz --strip-components=1`（同 WSL `installBundle` / `docker/Dockerfile`），落在 `<installPath>/bin/bat-server`；解完 `bin/bat-server` 不可執行即上傳失敗（`electron/remote/ssh-bundle-uploader.ts`）。**乾淨覆蓋安裝（T0552 / BUG-139，SSH 與 WSL `installBundle` 共用 `electron/server-bundle-install-script.ts`）**：先解到 `<root>.bat-new`、驗 `bin/bat-server`，再把舊 root 換名 `<root>.bat-old` → 新樹換入 → 刪舊樹，舊 bundle 已移除的套件（與 T0511 前的 `staging/`）不再殘留；下載 / 解壓失敗時舊安裝不動。刪除白名單只有 `<root>.bat-new` / `<root>.bat-old` 與舊 root，且舊 root 必須是 bundle 安裝（`bin/bat-server` 或 `staging/bin/bat-server`）或空目錄，其他內容（symlink、檔案、別的目錄）照舊疊上去、不刪；root 須為絕對路徑、至少兩段、不得為 `$HOME`（`assertBundleInstallRoot` + shell 內再檢）。WSL 以 `wsl -d <distro> --exec sh -c <script> sh <root> <tarball>` 執行（`wsl --` 會把參數交給 login shell 重新解析、丟掉位置參數，T0552 實測）。使用者資料 `~/.local/share/bat-server` 不在 root 內。**精靈升級的取消（T0554 / BUG-141）**：精靈安裝帶 keep-previous（WSL `installBundle(..., { keepPrevious: true })` = 腳本第三參數 `keep`；SSH upload `keepPrevious` = `keep=1`），換入後舊樹留在 `<root>.bat-old`，腳本 stdout 印 `BAT_BUNDLE_PREVIOUS=kept|none|unmanaged`，精靈只在安裝**成功**後記錄（WSL `ctx.state.wslBundleInstall`、SSH `state.sshBundleInstall`）。rollback：`kept` → 換回舊樹（`wsl:restore-bundle` / `ssh:uninstall-bundle` `mode: 'restore-previous'`，現 root 先換名到 `.bat-new` 再刪，`.bat-old` 不是 bundle 安裝 → `missing`、不動）；`none`（首次安裝）→ 照舊刪 root；`unmanaged`（疊在非 BAT 目錄上）→ 不刪；安裝**失敗**→ 不刪（T0552 起失敗時舊 root 本來就沒動；T0554 前的 rollback 會把它刪掉）。unit / service：WSL write-systemd-unit 在挑 port（可能停掉舊 server）**之前**取快照（`wsl-systemd:snapshot-unit`：內容、active、enabled，重試沿用第一次），rollback 有舊 unit → `wsl-systemd:restore-unit` 寫回內容與 enabled；SSH start-server 第一次執行時把 unit / plist 備份成 `<file>.bat-prev` 並回報 `previous`（`backupPrevious`），rollback `ssh:stop-server` `action: 'restore-previous'`。舊 server 原本在跑而舊 bundle 還要換回時，unit rollback 先讓服務停著（設 `wslServiceStartAfterBundleRestore` / `sshServiceStartAfterBundleRestore`），bundle 換回後才啟動（WSL `wsl-systemd:restart-service`；SSH restore 指令尾端 `startService`），不會讓舊 unit 跑新 bundle。精靈**完成**時 `WizardStep.finalize`（runner 在全部步驟成功後依序呼叫，失敗只記 warning）刪 `.bat-old`（`wsl:discard-previous-bundle` / `mode: 'discard-previous'`）與 SSH 的 `.bat-prev`（`action: 'discard-backup'`）。中途關掉 BAT：下次安裝時 root 不在但 `.bat-old` 是 bundle 安裝 → 先換回再繼續；`.bat-old` 不是 bundle 安裝或空目錄 → 安裝 / 清理中止、不刪（白名單未放寬）。linger 不還原。驗證：`electron/__tests__/server-bundle-install-script.test.ts`（真 `sh` + `tar`）、`electron/__tests__/upgrade-rollback-main.test.ts`、`src/components/setup-wizard/__tests__/wizard-upgrade-rollback.test.ts`；WSL 實機 `e2e/t0550-wsl-acceptance.spec.ts` 的 `T0554 cancel`（`BAT_E2E_T0550=1 BAT_E2E_T0554_CANCEL_AFTER_INSTALL=1`，`-g "T0554"`，隔離實例注入 fetch-fingerprint 失敗後按取消，需先 `npx vite build`）。**WSL 精靈升級沿用 port 與 profile（T0552 / BUG-138）**：`wsl:pick-server-port` 帶 `existing`（distro / unit 路徑 / service 名）時，讀既有 unit 的 `BAT_SERVER_PORT`（舊版 `BAT_PORT`）沿用；該 port 被佔用時先停舊 service 再探測（最多等 5 s），仍被佔用 = 別的程式 → 照舊掃描新 port；挑選失敗會把停掉的 service 再啟動（`pickServerPortForUnit`，`electron/wsl-systemd.ts`）。`write-profile` 遇到同 distro + 同 port（SSH：同 host / user / ssh port + 同 server port）的既有 profile 時更新它（名稱不變）而不新建，rollback 寫回舊值、不刪除（`ctx.updatedProfileId` / `updatedProfiles`）。SSH 的 server port 固定（預設 9876、不探測），enable 階段 `restart` 取代舊 server，沒有換 port 問題。systemd unit 的 `ExecStart` 與 launchd plist 的 `ProgramArguments` 以命令列帶 `--port <serverPort> --bind-interface localhost`（bat-server 自 T0272 起即支援，舊 bundle 相容；**不是** `BAT_REMOTE_PORT` / `BAT_REMOTE_BIND`，bat-server 不讀）；enable 階段 systemd 用 `enable` + `restart`、launchd 先 `unload` 再 `load -w`（重跑 wizard 會換上新 bundle / 參數）；verify（`sh -c` 迴圈最多 20 秒）要求服務自己的行程在該埠 LISTEN（systemd：`is-active` + MainPID 擁有 `/proc/net/tcp{,6}` 的 socket；launchd：`launchctl list` 的 PID + `lsof -iTCP:<port> -sTCP:LISTEN`），不用 `pgrep -x bat-server`（行程是 node，比對不到）。實機驗證：`e2e/pre5-ssh-alias.spec.ts`（`BAT_E2E_PRE5_SSH=1`，先 `node e2e/real-remote/t0510-ssh-alias-env.mjs up`）。
